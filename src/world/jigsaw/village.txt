# Village templates and pools for the jigsaw assembler (generation 3).
#
# These are original VoxelCraft designs, not copies of Minecraft's template
# files: the assembler, pools, weights and connector rules follow Java's
# jigsaw system, the buildings are our own. See docs/villages.md.
#
# Format (src/world/jigsaw.rs): `template <name>` ... `end` and
# `pool <name> [fallback <pool>]` ... `end`. In a template, `size x y z`,
# `projection rigid|terrain`, `key <char> <spec>`, then `layer <y>` followed
# by one row per z (north first), one char per x (west first). `.` leaves
# the world as it is and `-` is air in every template. Specs: `$role` (from
# the village style), a block name with underscores, or `door`, `bed_foot`,
# `bed_head`, `crop`, `job`, `chest`; `@dir` turns a block to face `dir` and
# `^dir` makes stairs climb toward `dir`, both in template directions (north
# is row 0); `/upper` is a door's top half. `jigsaw x y z dir name target
# pool` is a connector facing out of the template, and `home bx by bz sx sy
# sz` is a bed (its head) whose villager spawns at `s`.
