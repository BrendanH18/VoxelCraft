# Original VoxelCraft ancient cities (v0.16 track B). Pool names, pool
# weights and fallbacks follow Java 26.3's `worldgen/template_pool/
# ancient_city`; every layout here is original. Java's list elements (the
# three camps, the ice box) are single templates. All pieces are rigid.
#
# Layer y 0 is a piece's floor course. The start's floor sits at y -52
# (walk level -51): Java's `city_anchor` jigsaw at y -27 places it there.
# `ancient_city.rs` clears each piece's box above its floor (Java's
# `beard_box`), applies the processors and grows the sculk patches.
#
# Roles: $shrieker (a sculk shrieker that can summon), $candle2..$candle4
# (plain candles, unlit), $hanging_lantern (a hanging soul lantern).
#
# Connector names: a parent's `target` is the child's connector `name`.
#   wall_socket -> wall        city centre to its walls
#   path        -> path        city centre and paths to paths
#   wall_end    -> wall_end    wall to wall
#   plot        -> structure   walls and paths to buildings
#   sculk       -> sculk       buildings to sculk patches
