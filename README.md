You wake up on a beach with nothing. There's a forest behind you, a mountain
past that, and the sun is already going down.

**VoxelCraft** is a survival sandbox that plays like Minecraft Java Edition,
written from the ground up in Rust by people who love that game. It's not a
mod, a launcher or a reskin: the world generator, renderer, mobs, menus,
textures, sounds and music are all original code. It aims to feel exactly
right: Java Edition 26.3 is the reference, so recipes, loot, mob behaviour
and controls match what your hands already know.

It runs at hundreds of frames per second on a laptop, and the whole game
downloads in less time than it takes to read this paragraph.

> [!TIP]
> **v0.14 is on its way.** It bundles three releases' worth of content: the
> ancient city and the warden, trial chambers, villages built from
> templates, bastions, more than twenty new mobs and much more. Everything below is in
> the source today. [Build it](#build-from-source) to play now, or grab the
> current download and the game will offer v0.14 as soon as it ships.

### Everything you'd expect

- 🧱 **Over 1,100 of Java's blocks**: sixteen colours of wool, glass,
  concrete and terracotta, twelve wood types, copper that weathers,
  stairs, slabs, walls, doors and signs.
- 🔨 **Hundreds of Java recipes** and a recipe book that shows every layout,
  so you won't need a wiki open in another window.
- 🌾 **Farming and food**: wheat, carrots, potatoes, melons, pumpkins and
  beetroot, bees and honey, breeding, fishing, cooking and composting.
- 💧 **A world that moves**: flowing water and lava, falling sand, fire that
  spreads, TNT, rain, thunder and lightning, and redstone that powers doors,
  lamps and pistons.
- 🎮 **Five game modes**: Survival, Creative, Hardcore (one life, no second
  chances), Adventure and Spectator, at the difficulty you choose.
- 🎵 **An original soundtrack** with positional audio, and a separate volume
  for each sound category.

## 🚀 Install

Grab the latest version from
[**Releases**](https://github.com/BrendanH18/VoxelCraft/releases/latest):

| Platform | File | How |
| --- | --- | --- |
| **Windows 10/11** (x64) | `…-windows-x64-Setup.exe` | Run the setup wizard. |
| **macOS 13+** (Apple Silicon) | `…-macos-apple-silicon.dmg` | Open it and drag VoxelCraft into Applications. |
| **Linux, Intel Mac** | — | [Build from source](#build-from-source) with Cargo. |

> [!NOTE]
> The builds aren't signed by a verified publisher yet, so Windows or macOS
> may warn you the first time you open the game. Each download includes
> notes on how to continue, and the [release guide](docs/releases.md) has
> the details.

**It keeps itself up to date.** The game offers each new release on the
title screen and installs it with **Update and Restart**, backing up your
worlds first. Worlds and settings live in a
[separate data folder](docs/releases.md#player-data-and-old-saves), so they
carry over. See [Updating VoxelCraft](docs/updates.md).

**Bring your bots.** Host a world with `--agent-listen 127.0.0.1:4242` and
up to eight command-line players (scripts, bots or AI agents) can move, mine,
build, craft and fight through the `voxelcraft-agent` tool. Mobs treat them
like anyone else. See [LAN play](docs/lan.md) and
[hosted agents](docs/agents.md).

## ⚡ Under the hood

VoxelCraft is built for speed. Chunks generate and light in parallel on a
worker pool, greedy meshing packs faces into 12-byte quads that the vertex
shader unpacks, and every chunk shares one pooled GPU mesh arena. Smooth
lighting, ambient occlusion, reflective water, positional audio and the
music are all made by code at runtime.

Measured on 26 October 2026 on an **Apple M5** MacBook Pro running on
battery: a release build rendering a 360° sweep at 1600 × 900, with the GPU
synchronised every frame (median of three runs):

| View distance | Frame time | Frame rate |
| :-- | --: | --: |
| 256 blocks (`--rd 8`) | 2.73 ms | **~366 fps** |
| 512 blocks (`--rd 16`) | 7.53 ms | **~133 fps** |

Your numbers will vary with hardware, power settings and scene. Run the same
sweep yourself with `cargo run --release -- --bench-render --rd 8`.

**Faithful by design, and checked.** The parts of the game that are data
(recipes, loot tables, trades, mob stats, damage types, enchantments, status
effects) are compared against facts extracted from the Java 26.3 reference by
tools in [`tools/`](tools), and the test suite fails when they drift. The
[roadmap](docs/roadmap.md) lists every known difference. The
[architecture notes](docs/architecture.md) explain how it all fits together.

## 🛠️ Build from source

You'll need a recent stable **Rust** toolchain (edition 2024) and a GPU that
wgpu supports through Metal, Vulkan or DirectX 12. CI builds on macOS, Linux
and Windows.

```sh
# Debian/Ubuntu only: audio and gamepad headers
sudo apt-get install libasound2-dev libudev-dev libfontconfig1-dev libfreetype6-dev pkg-config

git clone https://github.com/BrendanH18/VoxelCraft.git
cd VoxelCraft
cargo run --release
```

Jump straight into a world, skipping the title screen:

```sh
cargo run --release -- --creative --world sandbox --seed 42
```

Most of the screenshots on this page come from seed 42, so go and find them.

<details>
<summary><strong>⚙️ Common command-line options</strong></summary>
<br>

| Option | What it does |
| --- | --- |
| `--creative` / `--survival` | Choose a game mode |
| `--world <name>` | Load or create `saves/<name>`, skipping the title screen (a world saved by a newer version asks first) |
| `--new` | Start the selected world fresh, replacing it when it saves |
| `--data-dir <dir>` | Use a separate folder for saves, options and logs |
| `--seed <n>` | Set the seed for a new world |
| `--rd <chunks>` | Render distance in 32-block chunks (default `8` = 256 blocks) |
| `--no-vsync` | Uncap the frame rate |
| `--graphics classic/enhanced` | Original look, or directional sunlight and reflective animated water |
| `--mute` / `--volume <0..1>` | Set audio at startup |
| `--agent-listen <IP:PORT>` | Host command-line players in this world ([details](docs/agents.md)) |
| `--split-screen <names>` | Show up to three hosted players in split-screen |
| `--help` | List every option, including benchmarks, screenshots and debug flags |

</details>

## 🧭 What's next

VoxelCraft is heading for a 1.0 that matches modern Java single-player
survival, one themed release at a time:

**v0.13** terrain ✅ → **v0.14** structures, wildlife, the deep dark and
trial chambers (next) → **v0.15** villages and raids → **v0.16** the End and
the Wither → **v0.17** redstone and automation → **v0.18** polish and
performance → **1.0**. Multiplayer grows after 1.0.
