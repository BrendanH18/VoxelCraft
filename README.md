VoxelCraft is a free, open-source survival sandbox that plays like Minecraft
Java Edition. Start in a field with nothing, work your way up to diamond,
light a portal to the Nether, track down a stronghold, and watch the credits
roll after the Ender Dragon falls. Nearly every texture, sound and song is
generated by code, and none of it comes from Minecraft.

### Pick your challenge

| Mode | What it's like |
| --- | --- |
| 🛠️ **Creative** | Unlimited blocks, flight, no danger. Just build. |
| ⚔️ **Survival** | Health, hunger, timed mining, experience and loot, at the difficulty you choose. |
| 💀 **Hardcore** | Survival on hard with one life. Die and you're a spectator for good. |
| 🧭 **Adventure** / 👻 **Spectator** | Explore without breaking things, or float through walls and watch. |

## 🚀 Install

Download the latest version from
[**Releases**](https://github.com/BrendanH18/VoxelCraft/releases/latest):

| Platform | File | How |
| --- | --- | --- |
| **Windows 10/11** (x64) | `…-windows-x64-Setup.exe` | Run the setup wizard. |
| **macOS 13+** (Apple Silicon) | `…-macos-apple-silicon.dmg` | Open it and drag VoxelCraft into Applications. |
| **Linux, Intel Mac** | — | [Build from source](#build-from-source) with Cargo. |

> [!NOTE]
> The builds aren't signed by a verified publisher yet, so Windows or macOS
> may warn you the first time you open the game. The installation notes in
> each download explain how to continue. See the
> [release guide](docs/releases.md) for details.

**Updates are automatic.** From v0.10 onward, a copy installed from these
downloads offers each new release on the title screen and installs it with
**Update and Restart**, backing up your worlds first. On v0.9 or earlier, install the latest version by hand once, over the
old one. Your worlds and settings live in a
[separate data folder](docs/releases.md#player-data-and-old-saves) and carry
over. Older versions can't open upgraded worlds, so keep a backup of any world
you care about. See [Updating VoxelCraft](docs/updates.md).

## 🌅 Your first night

From the title screen, choose **Singleplayer**, then **Create New World**.
Name it and pick a game mode and difficulty; the **World** tab takes an
optional seed. Worlds autosave every two minutes.

Click the window to grab the mouse. <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd>
moves, the mouse looks, <kbd>Space</kbd> jumps, **left click** mines or
fights, **right click** places or uses, and <kbd>E</kbd> opens your inventory.

The sun is already moving. Here's how to be ready when it sets:

1. 🌳 **Punch a tree.** Grab a few logs, open your inventory, and turn each
   log into four planks in the 2×2 crafting grid.
2. 🪵 **Make a crafting table** from four planks in a square, and some
   sticks from two planks stacked on top of each other.
3. ⛏️ **Craft a wooden pickaxe** on the table: three planks across the top,
   two sticks down the middle.
4. 🪨 **Mine some stone.** Eight cobblestone in a ring makes a furnace, and
   a stone pickaxe unlocks iron. Gold and diamond need iron or better.
5. 🍖 **Cook dinner.** Ore or raw meat goes on top of the furnace, fuel
   (coal, charcoal, wood or sticks) below. Hold right-click with food to eat.

Stuck on a recipe? Click **Recipes** in any crafting screen to flip through
layouts and copy them into your grid.

> [!WARNING]
> Dying drops everything you were carrying, and dropped items vanish after
> five minutes. Run back for your stuff!

  <tr>

      <h3>🎮 Couch co-op</h3>

      beside you with their own split-screen view, hotbar, health and hunger.
      Up to three controllers can join the keyboard player.

      Load a world, press <strong>Esc → Open to LAN</strong>, pick the

      with chat, a player list and optional PvP.
    </td>
  </tr>

You can also script players. Host a world with
`--agent-listen 127.0.0.1:4242`, and up to eight command-line players (bots,
scripts or AI agents) can move, mine, build, craft and fight through the
`voxelcraft-agent` tool. Mobs treat them like anyone else. See
[LAN play](docs/lan.md) and [hosted agents](docs/agents.md).

<a id="performance"></a>

## ⚡ Performance

Chunks generate and light in parallel on a worker pool. Greedy meshing packs
faces into 12-byte quads that the vertex shader unpacks, and every chunk shares
one pooled GPU mesh arena. Smooth lighting, ambient occlusion, reflective
water, positional audio and the soundtrack all come from code.

Measured on 26 October 2026 on an **Apple M5** MacBook Pro running on battery:
a release build rendering a 360° sweep at 1600 × 900, with the GPU synchronised
every frame (median of three runs):

| View distance | Frame time | Frame rate |
| :-- | --: | --: |
| 256 blocks (`--rd 8`) | 2.73 ms | **~366 fps** |
| 512 blocks (`--rd 16`) | 7.53 ms | **~133 fps** |

Your numbers will vary with hardware, power settings and scene. Run the same
sweep with `cargo run --release -- --bench-render --rd 8`. The
[architecture notes](docs/architecture.md) explain the renderer, and the
[development guide](docs/development.md) covers benchmarks and scripted scenes.

<a id="build-from-source"></a>

## 🛠️ Build from source

You'll need a recent stable **Rust** toolchain (edition 2024) and a GPU that
wgpu supports through Metal, Vulkan or DirectX 12. CI builds on macOS, Linux
and Windows.

```sh
# Debian/Ubuntu only: audio and gamepad headers
sudo apt-get install libasound2-dev libudev-dev pkg-config

git clone https://github.com/BrendanH18/VoxelCraft.git
cd VoxelCraft
cargo run --release
```

To skip the title screen, name a world on the command line:

```sh
cargo run --release -- --creative --world sandbox --seed 42
```

<details>
<summary><strong>⚙️ Common command-line options</strong></summary>
<br>

| Option | What it does |
| --- | --- |
| `--creative` / `--survival` | Choose a game mode |
| `--world <name>` | Load or create `saves/<name>`, skipping the title screen (a world saved by a newer version asks first) |
| `--new` | Start the selected world fresh, replacing it when it saves |
| `--data-dir <dir>` | Use a separate folder for saves, options and logs |
| `--seed <n>` | Set the seed for a new world |
| `--rd <chunks>` | Render distance in 32-block chunks (default `8` = 256 blocks) |
| `--no-vsync` | Uncap the frame rate |
| `--graphics classic/enhanced` | Original look, or directional sunlight and reflective animated water |
| `--mute` / `--volume <0..1>` | Set audio at startup |
| `--agent-listen <IP:PORT>` | Host command-line players in this world ([details](docs/agents.md)) |
| `--split-screen <names>` | Show up to three hosted players in split-screen |
| `--help` | List every option, including benchmarks, screenshots and debug flags |

</details>

## 🧭 Where it's headed

VoxelCraft is working toward a 1.0 that matches modern Java single-player
survival closely. Each release completes one area:

**v0.13** terrain → **v0.14** structures (next) → **v0.15** wildlife →
**v0.16** deep dark and trial chambers → **v0.17** villages and raids → **v0.18** the End and the Wither →
**v0.19** redstone and automation → **v0.20** polish and performance →
**1.0**. Multiplayer expansion comes after 1.0.

The [roadmap](docs/roadmap.md) lists the scope of each release, its acceptance
checks and the known differences from Java.
