; VoxelCraft's UI font: original pixel art drawn for this project on
; 2026-11-23 (v0.18 track 1). MIT OR Apache-2.0, like the rest of the
; repository. Nothing here is traced from another font. The advance of each
; character (its ink width plus one) matches Java 26.3's default font, so
; Java's layouts and the signs' 90-pixel line rule fit the same text; the
; widths are checked against tests/fixtures/java/26.3/font_metrics.json.
;
; Format (read by src/font.rs):
;   glyph C TOP      a drawn glyph; the rows follow, '#' ink and '.' empty,
;                    up to the next blank line. TOP is the row of the first
;                    line: 0 is the top of a capital, 6 the baseline row,
;                    -3 to -1 hold accents above capitals, 7 and 8 the
;                    descender and the marks below.
;   mark NAME PLACE  an accent: PLACE is `above` (one empty row above the
;                    base's ink), `touch` (directly on it), `below`
;                    (under the baseline, centred) or `ogonek` (under it,
;                    at the base's right edge).
;   compose C BASE MARK [MARK...]   C drawn as BASE with the marks; MARK@X
;                    puts a mark at column X instead of centring it.
; C is a character, U+XXXX, or a helper name used only as a base. Columns
; start at 0 on the left: the advance is the rightmost ink column plus 2.
; The space (U+0020) and no-break space (U+00A0) have no ink and advance 4.
