# Historical project records

[Documentation index](../README.md) · [Current roadmap](../roadmap.md) · [Current agent instructions](../../AGENTS.md)

These documents preserve earlier plans, allocation ranges, assignments,
implementation reports and audits. They are **superseded historical records**.
Do not execute their old branch, delegation, reference-version or release
instructions. Their checkmarks and test counts are reports from their original
context, not evidence that the current roadmap's acceptance criteria passed.

The records were migrated into the repository on 2026-10-12. Machine-specific
worktree paths and obsolete external-note setup were made portable. The
original source snapshot and its Git history were backed up locally during
migration; this archive preserves the useful project history, not local Git
metadata or operating-system files.
