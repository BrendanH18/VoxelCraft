## Remaining differences and evidence limits

- Original VoxelCraft designs are explicitly requested, but they do not
  establish Java's template-layout fidelity. No owner fidelity exception is
  inferred. The cold overlay geometry shares the original masonry motif;
  the primary template supplies sediment.
- Chest seeds still use the engine's deterministic positional stream rather
  than Java's decoration-time post-processing stream. Structure selection
  is represented by choosing the variant matching the biome in the shared
  grid, rather than replaying Java's weighted attempt ordering. Full Java
  world-seed coordinate/content parity remains unverified.
- Biome membership is sampled from the engine surface column; Java's
  height-dependent biome-coordinate parity remains unverified. Drowned
  markers reuse the existing resident machinery; Java structure-spawn
  equipment and population gating were not independently re-audited.
- Brushing currently uses the shared hand swing and block-hit sound. Java's
  dedicated brush particles/sounds and the progressively emerging item
  model are not implemented. Extracted drops use the engine's integer-cell
  drop queue rather than Java's exact fractional item-entity origin.
- The shared block ray does not include Java BrushItem's intervening-entity
  ray check. Other interaction-range and block-use priority rules are shared.
- Falling uses the existing engine's continuous gravity/drag approximation;
  its two-tick start and no-placement/no-drop outcome match BrushableBlock.
- This save format also preserves brush progress/deadlines; Java only saves
  loot/item and hit direction, and resets brush progress on block-entity load.
  Reloaded deadlines use the saved global simulation clock.
- The general warm-ocean-ruin explorer-map item from abandoned camps is still
  absent with that existing structure/map gap. Treasure maps **inside** ruin
  chests use the existing implemented buried-treasure map path.
- Trail-ruin/desert-well/desert-pyramid archaeological loot and processors
  remain deferred under narrowed DEF-02; existing ordinary sediment stays.
- No owner's ordinary play, GPU/frame-time acceptance, exact Java world
  comparison or LAN visual block-entity payload acceptance is claimed.
