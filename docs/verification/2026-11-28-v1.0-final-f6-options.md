## Scope

The UX-03 gaps the [release notes' known limitations](../../packaging/RELEASE-NOTES.md)
list for options, menus, chat and the raid bar:

1. Java 26.3's options the game lacked: Biome Blend, Entity Distance,
   Weather Effect Radius, Monochrome Logo, Darkness Pulsing, Directional
   Audio, the sound output Device, Narrator/Voice volume and Java's chat
   options; Language, Resource Packs and Skin Customization recorded if
   out of reach.
2. Difficulty and its lock on the pause menu, where Java 26.3 moved them;
   Create New World's More tab; Edit World's Optimize World and Export
   World Generation Settings where they apply.
3. The chat's scroll bar and scrolling back through it.
4. The raid bar for LAN guests.

What was done, item by item, is [below](#what-changed); what was not, with
the reason, is under [remaining differences](#remaining-differences).

## What changed

### Options (item 1)

Each is saved under Java's `options.txt` key, with Java's default when a
file has no line for it, and each changes what Java's changes:

| Option | Where | Java's label, range and default | Key | What it does here |
|---|---|---|---|---|
| Entity Distance | Video, after Entity Shadows | "Entity Distance: 100%", 50% to 500% in quarters, 100% | `entityDistanceScaling` | Multiplies `Entity.viewScale` in every view's `DrawDistance` (main view and split-screen), so entities draw `size * 64 * viewScale` blocks out as in Java |
| Weather Effect Radius | Video, last of Quality | "Weather Effect Radius: 10 Blocks", 3 to 10, 10, with Java's tooltip | `weatherRadius` | The rain and snow sheets' radius around the camera (main view and split-screen) |
| Darkness Pulsing | Accessibility, after FOV Effects | "Darkness Pulsing: 100%" (OFF at 0), 0 to 1, slider on the square root, Java's tooltip | `darknessEffectScale` | `LightmapRenderStateExtractor`: the lightmap's Darkness dimming is `blend * option` and its pulse `calculateDarknessScale(blend * option) * option`; the fog keeps the unscaled blend, as Java's does |
| Narrator/Voice | Music & Sound, between Ambient/Environment and UI | "Narrator/Voice: 100%" (OFF at 0) | `soundCategory_voice` | Java's Voice category, which only Java's narrator plays in; VoxelCraft has no narrator, so nothing plays in it |
| Chat | Chat | "Chat: Shown", Shown, Commands Only, Hidden | `chatVisibility` (Java's id 0, 1, 2) | Shown: every line. Commands Only: players' `<name>` lines are left out of the chat. Hidden: no lines show, and sending a message or command gives Java's "Chat disabled in client options." on the action bar |
| Colors | Chat | "Colors: ON" | `chatColors` | OFF draws the chat's only coloured text, the yellow bold `[Debug]:` prefix, plain, as Java strips formatting |
| Chat Text Opacity | Chat and Accessibility | "Chat Text Opacity: 100%" (shows `0.1 + 0.9 * v`), 1 | `chatOpacity` | The chat text's alpha |
| Text Background Opacity | Chat (and Accessibility, as before) | "Text Background Opacity: 50%" | `textBackgroundOpacity` | The chat rows' black backing, now Java's `ARGB.black(alpha * opacity)` |
| Chat Text Size | Chat | "Chat Text Size: 100%" (OFF at 0) | `chatScale` | Scales the chat about its top left (`pose.scale`), text included; OFF hides it |
| Line Spacing | Chat and Accessibility | "Line Spacing: 0%" | `chatLineSpacing` | Row height `9 * (1 + v)` and the text's offset in the row, Java's integer maths |
| Chat Delay | Chat and Accessibility | "Chat Delay: None", 0 to 6 seconds in tenths, "Chat Delay: 1.5 second(s)" | `chatDelay` | Players' messages wait in a queue and come out one per delay (`ChatListener.tick`), with Java's "[+n pending line(s)]" under the chat |
| Width | Chat | "Width: 320px", 40 to 320 pixels | `chatWidth` | Where the chat wraps and how wide its backing is |
| Focused Height | Chat | "Focused Height: 180px", 20 to 180 | `chatHeightFocused` | The rows the open chat shows |
| Unfocused Height | Chat | "Unfocused Height: 90px" (Java's 70/160 default) | `chatHeightUnfocused` | The rows the chat over the hotbar shows |

The Options screen gains **Chat Settings...** in Java's grid order (Music &
Sounds, Video Settings, Controls, Chat Settings, Accessibility Settings,
Credits & Attribution, Check for Updates), and loses Difficulty (item 2).
A Java `options.txt`'s `soundCategory_<name>` lines now read into the
matching volumes too; VoxelCraft keeps writing its own `volume_*` keys,
which every earlier release reads. Old files load unchanged (every
release's fixture options file still loads and resaves stably).

`--open-menu chat` and `--open-menu world` open the new screens for
captures.

### World Options on the pause menu (item 2)

The pause menu has Options... and **World Options...** side by side, as
Java 26.3's does; Open to LAN keeps a row of its own (see below). World
Options is Java's screen with its General header and Difficulty with the
lock button at its end. A change waits for **Apply Changes** (greyed until
something changed); **Cancel** and Esc drop it. Applying a lock asks
Java's "Lock World Difficulty" question naming the chosen difficulty: No
goes back to World Options, Yes applies the difficulty, locks it and goes
back to the pause menu. A locked or hardcore world shows the difficulty
greyed with Java's tooltips ("Difficulty is locked.", "Cannot change the
difficulty in a hardcore world.") and the lock greyed. Choosing Peaceful
still clears hostile mobs, as before.

### Create New World's More tab (item 2)

Create New World has Java's third tab, **More**, with Java's three
210-pixel buttons: **Game Rules**, Experiments and Data Packs. Game Rules
opens Java's **Edit Game Rules**: the rules under Java's category headings
(Chat, Drops, Miscellaneous, Mobs, Player, Spawning, World Updates, in the
order of their ids), each rule by Java's name (`gamerule.minecraft.<id>`,
read through the jar's `deprecated.json` renames from its `en_us.json`)
with a 44-pixel ON/OFF button or number box at the right and Java's
tooltip (the id, the description where Java has one, "Default: x"). A
number out of the rule's range greys Done. Done keeps the rules for the
world being created, Cancel drops them; the world starts with them, and
`--gamerule` still sets over them. Existing worlds keep their saved rules.

### Edit World (item 2)

Java 26.3's Edit World has Reset Icon, Open World Folder, Make Backup,
Open Backups Folder and Optimize World; Export World Generation Settings is
gone from it, so there is nothing to add for export. Optimize World is
recorded below.

### Chat scrolling (item 3)

The open chat is now Java's `ChatScreen`: the focused chat (every row at
full opacity, Focused Height's rows) above Java's input strip (black at
the text background opacity, two pixels in from the screen's sides, the
input at (4, height − 12)), in place of VoxelCraft's own panel and help
line. The chat keeps Java's 100 lines (was 64). The wheel scrolls back
seven rows a notch (one with Shift) after Scroll Sensitivity and Discrete
Scrolling, Page Up and Page Down a page less one, never past the oldest
row. Java's scroll bar shows at the chat's right edge when there are more
rows than fit, blue, turning red when a line comes in while scrolled back
(the view then keeps its place). Sending a message, or closing the chat,
returns to the newest line.

### The raid bar for LAN guests (item 4)

The host's state snapshot for each guest carries the raid bar that guest's
player is on (`raid_bar`: the title code and progress), and a guest draws
it as the host draws its own, under any other boss bar: "Raid", "Raid -
Raiders Remaining: n", "Raid - Victory" or "Raid - Defeat" with the red
notched bar. A snapshot without one (no raid, or a host from before this
change) hides it. The CLI agent already had it in its state (`raid`).

## Remaining differences

- **Biome Blend** (`biomeBlendRadius`) is not added: VoxelCraft tints
  grass, foliage and water by giving each block column a biome class that
  picks a pre-tinted texture layer, so there is no colour to average over
  Java's 3×3 to 15×15 squares. Matching Java needs per-vertex tint colours
  in the mesher and shaders; recorded, not decided.
- **Sound output Device** (`soundDevice`) is not added: the audio thread
  opens cpal's default output once for the whole run; Java reloads its
  sound engine on the chosen device. Needs the audio thread to reopen its
  stream (and track F4 owns the mixer tonight).
- **Directional Audio** (`directionalAudio`) is not added: the mixer pans
  in stereo; Java's option switches OpenAL's HRTF. Needs an HRTF in the
  mixer.
- **Monochrome Logo** stays out: it recolours Java's Mojang Studios
  loading screen, which VoxelCraft doesn't have (as Track 7 recorded).
- **Web Links and Prompt on Links** are not added: no chat text is
  clickable in VoxelCraft, so there are no links to open or prompt for.
  Command Suggestions, Hide Matched Names, Reduced Debug Info, Only Show
  Secure Chat, Save Unsent Chats and the Narrator are left off Chat
  Settings for the same reason (nothing behind them).
- **Language, Resource Packs, Skin Customization, Online and Telemetry**
  stay off the Options screen: VoxelCraft ships English text only, has no
  resource pack loader (its art is original and generated), no player
  skin layers to toggle beyond the one original skin, and no online
  services. Each needs a feature of its own, not an option.
- **Chat: Commands Only** tells players' lines apart by their `<name> `
  start, the form every player message takes in VoxelCraft; Java tags each
  message's source. Hidden shows nothing, even with the chat open; which
  system lines Java still shows under Hidden (its server filters them with
  `acceptsSystemMessages`) wasn't checked against the server classes.
- **World Options** has only Java's Difficulty and lock. Java's Default
  and Personal Game Mode, Allow Commands, Edit Game Rules, Restrictions
  and its Multiplayer section (LAN on/off, port, guest command access,
  Force Game Mode) aren't on it; Open to LAN stays a pause-menu row with
  VoxelCraft's own LAN screen. A LAN guest sees no difficulty (Java shows
  it greyed with the operator tooltip).
- **Create New World's More tab**: Experiments and Data Packs are greyed
  with VoxelCraft's own tooltips (it has neither experimental features nor
  data packs). Edit Game Rules lists only the rules VoxelCraft enforces
  (Java lists all 59), has no search box, and draws rule names in the
  options list's left column rather than Java's wrapped labels. No world
  has an in-world rule editor (Java's World Options has Edit Game Rules);
  `/gamerule` changes them.
- **Optimize World** is not added: VoxelCraft has no chunk upgrade pass to
  run over a whole world (it reads old saves as it loads them).
- **Export World Generation Settings** is not applicable: Java 26.3's
  Edit World no longer has it (only its translation remains).
- The chat keeps one line per message without Java's per-message tags,
  icons, hover text or the restricted-chat prompt.
