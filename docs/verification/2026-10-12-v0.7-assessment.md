branch contains useful implementations to retain. Existing tests pass, but

Specific independent reference failures on the pending committed source:

- Bamboo, bamboo block/mosaic, dried kelp block, oak slab/stairs/door, ladder and
  blaze rod lack their expected fuel values; actual smelting does not start for
  bamboo mosaic. Save interruption does not hide that failure.
- Pufferfish does not transform awkward normal or splash potions into Water
  Breathing; the brewing/save scenario consequently never starts.
- The current lead recipe requires the old slimeball ingredient. Java 26.3 uses
  five string and produces two leads. A saddle now crafts from three leather
  and one iron ingot; that recipe is absent from the pending branch.

These are normalized facts from the selected artifact, not assumptions based
on the Rust implementation or the old Java 1.21 briefs. Lead/saddle fixtures
are retained for future integration; the 0.6 baseline does not register those
items and this assessment does not allocate replacement IDs.

## First delivered source changes

- `536923b`: shared `content::PLANKS` ingredients and fuel metadata, missing
  fuel integrations, explicit Nether-plank exceptions, integer fast-furnace
  fuel reduction and pufferfish Water Breathing brewing. Five integration
  cases cover reference values, bottle types and interrupted container saves;
  a unit case covers existing shaped wood families.
- `05f3f10`: shared bucket/bottle execution used by the desktop/controller
  client and CLI agents, including ordinary pouring after a missed creature
  capture. Presentation consumes typed effects. Eight integration cases cover
  CLI/client-entry consistency, pickup, creative handling, overflow, Nether
  evaporation, cow milking, invalid actions and creature payload round trips.

No block/item/state IDs, save formats, package versions or pending implementation
branches were changed. Other crafting tags, loot and compost integration still
need migration and full coverage.

## Performance smoke, not frame-rate acceptance

The existing headless benchmark ran with seed 12345 and `--rd 8` on the M5.
These are individual smoke runs, not controlled medians or rendered-frame results.

| Source | Generate ms/chunk | Light/mesh ms/dense chunk | Stream seconds |
| --- | --- | --- | --- |
| Baseline `259b21c` | 0.482 | 0.924 | 0.43 |
| Pending `f5bf0d1` | 0.489 | 0.930 | 0.43 |
| Assessment fixes `05f3f10` | 0.451 | 0.919 | 0.44 |

All runs produced 236 dense/352 uniform generation chunks, 371068 mesh quads,
and 3516 loaded/2364 meshed streamed chunks. No generation/mesh output change
was observed. Timing differences in one-shot runs are not evidence of an
optimization or a comprehensive no-regression result. This benchmark does not
measure bucket/furnace gameplay workloads or the 1080p/240 FPS gate; STR-01's
representative gameplay, frame-time, streaming and memory suite remains open.

## Integration direction and next work

The committed v0.7 branch and these source fixes produce a clean trial merge
tree. It is exported and tested separately; neither branch has been merged
into the other by this assessment. This makes retaining the existing work
plausible without a duplicate implementation, while keeping its acceptance
gaps visible.

Reproduce that trial from the recorded source commits with
`git merge-tree --write-tree 05f3f10 f5bf0d1`, then export the returned tree with
`git archive` into a disposable directory. The tested tree was
`b1bad377e2d803e986fa9258b294b4d0996f2236`. Formatting, strict release Clippy and
all desktop release tests passed: **838 tests**, three ignored, including the
new reference cases, bucket cases and existing v0.7 release/LAN regressions.
This compatibility check is not ordinary-player or release acceptance.

Before integrating or releasing v0.7:

1. Correct lead/saddle acquisition against the pinned fixtures and expand the
   modern-version inventory for the animal/mount content.
2. Review and retain the turtle activity gating and save-lock improvements.
   Recheck old saves and real restart behavior on supported platforms.
3. Finish ordinary-player/controller checks and representative gameplay
   performance. Preserve existing LAN functionality without expanding its scope.
4. Address the remaining baseline gaps in priority order: authoritative light,
   spawn/navigation foundations, sponge behavior, composting, material families,
   plant growth and progression integrations. Do not erase the failed cases.

STR-01 now has a first independent fixture slice. STR-02 and STR-03 have first
shared content/action implementations; all three remain Partial. The full
benchmark scene suite, asset pipeline, broader session extraction and workspace
split remain planned. No 1080p/240 FPS acceptance result is claimed.
