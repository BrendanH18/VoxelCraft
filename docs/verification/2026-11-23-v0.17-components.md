## Fixture

[`redstone_components.json`](../../tests/fixtures/java/26.3/redstone_components.json),
written by [`tools/extract_java_redstone_component_fixtures.py`](../../tools/extract_java_redstone_component_fixtures.py)
([README](../../tests/fixtures/java/26.3/README.md#redstone-components-v017-track-e2)).
It resolves each `Blocks.<clinit>` registration's factory lambda to the
class it constructs (extending the shared `java_block_properties`
evaluator, including the colour and copper collections), then walks each
class's hierarchy below `Block` for signal-method overrides, `SignalGetter`
power queries and literal `scheduleTick` delays. 237 blocks in 75 classes;
each class names the v0.17 track that owns it. A few constants are asserted
in bytecode and recorded: the daylight detector's 20-tick sample, 0.2 sun
easing and `getEffectiveSkyBrightness`, the lightning rod's 8-tick pulse,
the copper bulb's lack of a scheduled tick, the lamp's 4-tick off delay
and the trapped chest's `clamp(openCount, 0, 15)`.

## What changed

- **Comparator outputs** (`World::container_signal`,
  `redstone_catalogue::state_analog_output`): cake `(7 - bites) * 2`,
  candle cakes 14, cauldrons (empty 0, water and powder snow their level,
  lava 3), respawn anchors `floor(charges / 4 * 15)`, end portal frames 15
  with an eye, and decorated pots as one-slot containers. Before, a
  comparator read the power behind these blocks instead, as if they had no
  analog output.
- **Decorated pots wake comparators** when an item goes in
  (`BlockEntity.setChanged`).
- **Observers see fire age.** `FireBlock.tick` writes the new age with flags
  260, which still update neighbour shapes; the game's edit path returned
  early for fire-age changes and skipped observers. The observer check is
  now `World::notify_observers`, called from both paths.
- **`world::redstone_catalogue`**: one cold-path `role(Block)` (source,
  strong, analog, reads power) built from the same predicates the engine
  dispatches on, for the comparison below.

Audited against Java and found already matching (no change): the daylight
detector's sun-angle formula and propagated sky light, copper bulbs
(toggle on the rising edge in the same tick: 26.3 has no delay), lightning
rods, the lamp's delays, targets, trapped chests (viewers, strong only
downward), lecterns, jukeboxes, note blocks under mob heads (v0.16), the
redstone block, redstone ore, buttons (30 ticks for every wood, 20 for
stone and polished blackstone), plates, every door, trapdoor and fence gate
(all woods including poplar, iron and copper), the bell's rising-edge ring
and TNT.

  every state-only comparator output and a comparator behind a cake;

  and iron doors; redstone ore.

## Differences from Java

- The game's tripwire uses one texture whether attached or not; Java 26.3
  draws the same geometry with another strip of the texture when attached.
  (The "sag" the plan mentioned is not in 26.3's models.)
- Update order, tick priorities and the block-event queue remain Track A's;
  timing above holds in game ticks, not within-tick order.
- Command, structure and test blocks (registry gaps, `release: none`) and
  the crafter (Track C1) are not in the game.
- Note-block substrate instruments are not compared with Java's
  `instrument` properties block by block (an existing, recorded gap).
