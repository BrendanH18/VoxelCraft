  movement sink to retry; partial paths whose endpoints cannot interact are
  remembered as unreachable. When merging, Java subtracts free slot capacity from the
  carried count, even if fewer items moved; the resulting empty stack is handled
  as empty. This implementation subtracts the actual moved amount and never
  constructs a negative/underflowed count.

## Implementation and parent contracts

`entity::copper_golem::State` is `Mob::copper_golem: Option<Box<State>>`.
State carries the full `Stack` for cargo and antenna, oxidation and deadline,
interaction/queue/visit state, and readiness. Existing mob names/identities/leashes
remain on `Mob`. Enum/ALL appends after Ocelot at LAN index 68; old indices stay.

- `Entities::spawn_copper_golem(pos, stage, waxed) -> usize` creates a persistent
  golem and queues its spawn sound, returning its mob index. Parent commits
  construction/reactivation blocks before calling it.
- `State::spawn(stage, waxed)` initializes construction/reactivation state.
  Parent sets this on a spawned `MobKind::CopperGolem`; emit
  `MobSound::CopperGolem(Sound::Spawn, stage as u8)` at successful spawn.
- `wax() -> bool` means consume one honeycomb on true. `scrape() -> bool`
  means apply one axe durability on true; check the prior `waxed()` value to
  choose the wax-off/scrape effect. Both invalidate statue readiness.
- `take_cargo() -> Option<Stack>` transfers ownership to parent for empty-hand
  throwing. `equip_antenna(one_poppy) -> Option<Option<Stack>>` returns outer
  None if ineligible **or occupied**, otherwise Some(None) after equipping.
  Parent owns held-item consumption. `shear() -> Option<Stack>` removes
  the poppy; parent applies shears wear and drops that exact stack.
  Parent must check alive/range/authority before all interaction APIs.
- `statue_ready` is a latched request, **never deletion**. Parent must recheck
  alive/oxidized/unwaxed/air cell, successfully place/store the statue and
  copy only CUSTOM_NAME, drop the exact cargo and antenna stacks unconditionally
  (including Vanishing / mob-loot disabled), and account for the leash before
  removing the mob without its death/ingot-loot path. Lead dropping follows
  ENTITY_DROPS separately. Failed
  placement leaves the mob and every component intact. No statue dependency.
- `Entities::tick_copper_golems(dt, &mut World)` is already called by the shared
  `update_world` bridge before mob physics. Do not call it twice. It uses
  `Entities::clock_time` for deadlines. Standard app callers currently populate
  that field from day count/time; a separate monotonic game clock would avoid
  time-setting commands altering deadlines. Parent owns any broader clock fix.
- `State::save/load` are wired through existing mob persistence and `look` /
  `apply_look` LAN render state. Loading resets transient navigation/openers,
  retaining exact cargo, antenna, stage, absolute deadline and the bounded
  visited/unreachable Brain memories with their loaded-tick TTL. Model snapshots
  include interaction pose/ticks and carried item components.
- World container access uses existing slot-order/double-chest APIs and one
  synchronous chest+hand mutation. The BTree spatial index bounds searches to
  local rows; per-tick opener/cat caches avoid per-golem full entity scans.
  Golem viewers stay separate from player screen reconciliation and contribute
  to existing aging/trapped-chest viewer counts. No block/item/texture IDs.
- Original riveted box model, four oxidation palettes, poppy and textured carried
  item use the existing entity/item mesh. Original damped-metal synthesis covers
  spawn/spin/step/get/no-get/drop/no-drop/shear/statue/hurt/death; new sound keys
  append after the old sound bank, retaining old LAN sound indices.
