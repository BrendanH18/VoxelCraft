# v0.8 player acceptance checklist

[Roadmap](../roadmap.md#v08-scope-finish-m0-and-m1) · [Requirement inventory](../requirements.md)

The owner plays through this list to give v0.8's rows the "player" evidence
the [inventory](../requirements.md) requires. Use a release build of one
recorded commit for the whole pass. Mark each line **Pass**, **Fail** (with
what happened) or **Skip** (with why). A failure goes back to the agents;
it is not marked Verified until a re-test passes.

Console commands below use the in-game console (**/**, **T** or **`**).
"Save and reload" means Save and Quit to Title, then reopen the world.
