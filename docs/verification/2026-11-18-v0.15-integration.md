## Integration changes

- **Orderings made contiguous**, recorded in
  [the reservations](../architecture.md#v015-villages-and-raids-track-reservations):
  - `MobKind` and `Voice`: Track A's five illagers take LAN indices 75–79 and Track C's five new mobs 80–84. `MobKind::ALL` and `Voice::ALL` were resized for all ten, and the block texture-end table for every track's layers.
  - Item icons after the bundles: Track B's (spyglass, the two books, the ten pattern items), then Track D's (spectral arrow, the two eggs, the 18 templates). Track F's five maps draw from its block texture layers 4056–4065, as the other maps do, so they take no item icons.
- **Hero of the Village pricing.** Track E's `Villager::heroes` now feeds Track H's `special_price_diff` through `Villager::priced_for`, so the price is cut by one formula only (Java's `updateSpecialPrices`).
- **Mansion map offer.** Track H's master cartographer `woodland_mansion_map` offer is kept and Track F's duplicate line is dropped. Track F's `master_cartographer_sells_the_woodland_mansion_map` test now passes against Track H's table.
- **Loot tables.** `src/world/loot_tables.json` has Track G's village and trial tables and Track F's `woodland_mansion` table. It was regenerated with the merged `tools/extract_java_structure_loot.py` from the 26.3 server jar, and the content matched the hand merge exactly.
- **Other overlaps.** The scheduled-tick dispatch takes the lectern pulse, frosted ice and the dried ghast in turn. Mob saves carry Track A's `illager` and `can_pick_up_loot` keys alongside Track C's `happy_ghast` and `nautilus` keys. Crafting registers Track B's, Track D's and Track C's recipes.
- **Generation 4.** New worlds save `worldgen=4`. Mansions and the template catalogues generate only there. `generation_3_chunk_hashes_stay_identical` pins generation 3, and the generation 1 and 2 pins pass unchanged.
