# v0.16 wave 1 integration — 2026-11-20

Status: **Implemented, unverified.** No owner play. This record covers
merging v0.16's four wave 1 tracks onto `t3/v0-16-end-and-wither`. The
scope is in the [roadmap](../roadmap.md#v016-scope-the-end-and-the-wither),
and each track's own record lists its Java sources, tests and differences:

- [A. Outer End](2026-11-20-v0.16-outer-end.md): End cities and ships,
  shulkers, chorus, purpur and End rods.
- [B. Flight and storage](2026-11-20-v0.16-flight-storage.md): shulker boxes,
  elytra and fireworks.
- [C. Wither and beacons](2026-11-20-v0.16-wither-beacons.md): mob heads, the
  Wither, wither roses, Nether stars and beacons.
- [D. Generation 5 Overworld](2026-11-20-v0.16-generation-5-overworld.md):
  poplar, cinnabar and sulfur, the sulfur cube, nether gold ore and
  abandoned camps.

Wave 2 (Tracks E, F and G) was not started: the owner asked for wave 1 only
in this push.

## How it ran

The base commit `566f6a90` added `Generation::V5` and pinned generation 4's
Overworld, Nether and End on two seeds
(`generation_4_chunk_hashes_stay_identical`). It also reserved each track's
IDs in the [architecture reservations](../architecture.md#v016-the-end-and-the-wither-track-reservations).

The four agents ran in their own worktrees. The session ended while they were
running. Tracks B and D had committed their work. Track A's record and all of
Track C's work were uncommitted, and were saved as WIP commits on their own
branches. New agents then finished A and C and built the parts of D that
were missing: the sulfur cube and abandoned camps. A, B and C each passed
`scripts/remote-check.sh --full` on their own. D's agent stopped before its
own run, so the integration checks below cover it.

On 2026-11-20 the owner moved focused builds back to the Mac, with Namespace
kept for hand-off checks only (AGENTS.md).

## Merge

The tracks landed in the order B, C, A, D. Most conflicts were appends to the
same lists; the [integrated order](../architecture.md#v016-the-end-and-the-wither-track-reservations)
records the result:

- `MobKind`: Wither (LAN 85), Shulker (86), SulfurCube (87).
- `Sound` is chained Flight, Wither, Beacon, SulfurCube.
- Item icons follow B, C, D.
- The `slab_stair_states` families are purpur, then Track D's seven.

Integration also added what the tracks had left for it:

- End ships hang an item frame holding an elytra. `populate_end_cities` hangs
  it the first time a player comes near, like the sentries.
- End ships carry a dragon wall head on the bow, backed by a purpur block.
- Mob heads join elytra in `Item::wear_slot` and `is_epic`. Heads still can't
  be swapped on by using them.
- The wither rose's pot joins Track D's pots in `utilities::other_pot`.

## Fixes found by the checks

- **Item icons:** `sprite_for_layer` now skips Track A's chorus items, which
  draw block layers. Before the fix, Track D's icons drew three slots late.
- **Sulfur cube:** its `biome_chance` is 0 outside sulfur caves, matching its
  spawn list. The model test treats it as a plain cube.
- **Abandoned camps:** the legacy sparse-structure test skips generation 5
  camps. The bundle test counts camp barrels and chests as live tables.
- **Sulfur cube model:** its functions were moved above the test module.
