## Source and procedure

Measured commit: `94a34ddb0ceb011cee6f68c899c8654103182da6`, clean at build
and measurement start. Runtime source fingerprint:
`0b1d7f17a78c8d30c3fbfa4ce9b5da8c6a2b52b0d1cb71884409ffc851c814a7`.
The summary records the executable SHA-256; all 15 reports match the source
stamp. The immutable measured binary remains in ignored local benchmark output.
Subsequent placement edits were prepared while this fixed binary ran; no builds
ran during measured scenes.

Hardware: Apple M5 MacBook Pro, 10 logical CPU cores, 10 GPU cores, 16 GiB RAM,
macOS 27.0.1, native display 3024 × 1964. Power/thermal telemetry was not recorded.
Measurement: 1920 × 1080 physical pixels, normal uncapped window surface,
VSync disabled, enhanced graphics, seed 12345, 256-block view range (`--rd 8`),
128-block simulation distance. Every run reports an eligible configuration.
The specification and recorded overrides describe camera flight and initial health.

Three independent runs per scene: ten seconds of warm-up, then 60 seconds for
survival/building/entities/automation and 180 seconds for streaming. The runner
starts fresh worlds sequentially. This is the initial suite; the broader
environment/encounter matrix, native resolution and player interactions remain
separate acceptance work.

```sh
CARGO_TARGET_DIR=/path/to/cache python3 tools/benchmark_scenes.py --repeats 3 --output target/benchmarks/m5-baseline
```

Every 60-second run completed 1,200 simulation ticks; every streaming run
completed 3,600. All recorded zero discarded simulation milliseconds. Frame
hitches still matter even though these runs retained fixed-step simulation time.

Process-memory variation, especially in entity/automation scenes, requires
investigation. GPU timestamps and allocation telemetry were unavailable.
CPU/GPU attribution, long-session memory bounds and performance relative to
Java remain unmeasured. Comparable pre-change scenes and profiling are needed
to attribute individual changes' costs.

## Artifact verification and next work

All 15 compressed raw sample sets were re-read independently. Sample counts,
the reciprocal mean of the slowest rounded-up 1%, nearest-rank p99 and counts
above 50 ms reproduce the reported statistics. The preserved executable's hash
matches the summary. Raw statistics and hardware/configuration metadata are
tracked; compiled binaries and temporary worlds remain outside version control.

Next: profile CPU/GPU submission, mesh upload and streaming/light work; verify
scene population/readiness and explain memory variation; establish explicit
hitch/queue budgets; optimize measured bottlenecks and repeat affected scenes.
Capture native resolution and the wider encounter matrix before full acceptance.
