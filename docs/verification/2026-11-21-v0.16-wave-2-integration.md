## How it ran

The owner approved wave 2 and Track H on 2026-11-21. The integrator ran on
the owner's Raspberry Pi, with every build and test in Boat
([AGENTS.md](../../AGENTS.md)). The Boat account was still on its free
trial, which can't start `large` sandboxes, so the full checks were
refused; the owner upgraded the account before the tracks started.

E, F, H and G ran at once, each in its own worktree. The M3 exit corpus,
planned as part of Track G, needs E's and F's structures, so it became its
own audit, started from the branch with E, F and H merged.

Before the tracks started, the integrator built the warm Boat snapshot
(`voxelcraft-warm`). Its first run failed
`update::backup::tests::unreadable_folders_fail_the_backup`: Boat runs the
tests as root, which can list a folder of mode 0300. The test now skips
itself when permissions aren't enforced (`ff2ebdf`), and every track
picked that commit.

## Merge

The tracks landed in the order E, F, H, G, then the audit. Conflicts:

- **Appended lists.** F and H both appended to the dimension property
  keys, `Sound`, the world's state, its tick and `set_block`'s trackers; G
  appended to the keys and the entity props. Every side is kept in landing
  order ([architecture](../architecture.md#v016-the-end-and-the-wither-track-reservations)).
  `Sound` gained a `CONDUIT_END` boundary so the conduit's and the geyser's
  cues keep their own ranges.
- **Python bytecode.** E and H had committed `tools/__pycache__/*.pyc`. It
  is removed, and `.gitignore` now ignores `__pycache__/` and `*.pyc`.
- **Docs.** Each track's appended paragraphs are kept. In the requirement
  inventory the GEN rows take the audit's text, except GEN-04b and GEN-04c,
  which keep Track G's portal and gateway parity and add the audit's note.

No IDs moved and no `MobKind`, `Effect` or item icon was added, so
`lan::PROTOCOL` stays 5, which wave 1 already set apart from v0.15.
