# v0.7.0 defect inventory — 2026-10-13

The owner's release bar for v0.7.0: every known defect or Java 26.3 difference in
features that already exist is fixed before release; no new features. This is
the working checklist, compiled from the roadmap, every verification record and
the feature docs (each item cites where it is recorded). Sizes: S under an hour,
M a few hours, L a day or more. Check items off as they land, with the commit.

**Scope decision (owner, 2026-10-13):** v0.7.0 fixes every small (S) and medium
(M) item below. The large (L) rewrites are the v0.8 plan at the end of this
file and are listed as known limitations in the v0.7.0 release notes.

Content that was never implemented (spears, mace, trident, the Wither, End
cities, raids, ancient cities, banners, signs and the 171 unregistered reference
fuel items) is out of this release by the owner's direction. Items marked
*by design* are licensing or scope constraints (original assets and music,
original terrain noise) to record as explicit exceptions, not defects.
