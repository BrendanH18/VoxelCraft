## Implemented behavior

- Torchflower crop ages 0–1, farmland planting, Java soil/crowding speed,
  two-thirds tick gate, brightness 9 growth and one-age bone meal;
  growth replaces age 1 with the torchflower. Both crop ages drop one seed.
- Pitcher ages 0–4, all ten half/age states, farmland planting, shared
  soil/crowding speed and brightness 8 growth; age 3 creates the upper half,
  growth to 4 updates both halves. Air or pitcher crop above is required.
  Bone meal on either half resolves to the lower half and advances once.
  Breaking either half cleans the partner; only the lower half yields a
  pod before maturity or one pitcher plant at age 4. Pitcher flower items
  place two halves and drop once. Both names preserve bee flower lookup.
- Potted torchflower through existing flower-pot interaction/model/drop
  paths; one orange dye per torchflower, two cyan dyes per pitcher plant,
  compost values, Night Vision (100-tick) suspicious stew. Bees can boost
  torchflower crops; existing mooshroom flower lookup recognizes them.
  Both new seeds join the shared chicken/parrot food predicate, matching
  Java's `chicken_food` and `parrot_food` tags.
- Sniffer: 14 health, movement attribute 0.1, 1.9 × 1.75 adult box,
  no natural spawning or death items, existing animal XP and feeding
  adapters. Snifflets start at -48000, grow on loaded ticks and can be fed
  seeds to shorten remaining growth. Seeds tempt and breed; breeding lays
  one egg item and gives the usual parent cooldown/XP, without a live child.
- Saved activity poses: idle, happy, scenting, sniffing, searching, digging,
  rising; shared ground movement, six original legs/moss-backed body/nose,
  procedural voice. Digging checks the expanded Java block tag, excludes
  remembered positions in the same dimension, emits a single gift at tick
  120, digs for 160–180 ticks, rises for 40 and sets a 9600-tick cooldown.
  The gift uses the world's persistent `minecraft:gameplay/sniffer_digging`
  random sequence, choosing seeds/pod equally even with mob drops disabled. Explored memory is Java's
  newest position plus up to 20 previous positions (21 total).
- Egg hatch 0–2, each loaded scheduled interval 8000–8299 ticks,
  4000–4299 over moss block only (pale moss is not the boost tag).
  Cracked states persist; hatching produces a persistent snifflet.
  Every crack state drops one egg without Silk Touch. Existing scheduled
  tick persistence and load tracking retain pending hatches.
- Mob state saves through the existing entity JSON path; explored dimensions,
  activity progress, cooldown, target and the already-emitted gift latch
  survive restart. Saved dimension codes are 0 Overworld, 1 Nether, 2 End.
  LAN look state includes pose/progress. Explicit wire
  mapping uses reserved 71 while the other track kinds await integration.
  Console/agent name lookup and creative items use the existing catalogue.

## Differences and unfinished work

This is not a full port of Java's brain. Search follows Java's five
`LandRandomPos` attempts (horizontal radii 10, 12, 14, 16, 18; vertical
radius 3), using the existing bounded navigator and a reached path with
accuracy one. Exact brain scheduling and engine navigation remain unverified.
The shared cow goal adapter supplies
panic, courtship, temptation, parent following and strolling; Java's
sniffer-specific brain goal ordering and timings are not reproduced in
full. Dig target geometry uses the selected block/nearby body position,
not Java's precise head offset. Search also requires air above the diggable
block; Java relies on navigation reachability instead, allowing some vegetation.
The reachability check uses the shared navigator. These are fidelity
gaps, not approved parity exceptions. The 21-entry memory is saved by
dimension, but activity target migration between dimensions is untested.

Sound cues and particles (2026-11-06) follow the Java call sites, with
original synthesized sounds (`src/audio/sniffer.rs`, `Sound::Sniffer`):
`transitionTo` plays scenting, sniffing, digging-stop (entering rising) and
happy; `dropSeed` plays drop-seed with the gift; `playSearchingSound` plays
searching every 20 ticks; `SnifferSoundInstance` loops `SNIFFER_DIGGING`
while searching or digging, approximated by a one-second dig cue every 20
ticks; `emitDiggingParticles` sprays the dug block between 1.7 s and 6 s of
the dig and plays its hit sound (volume and pitch 0.5) every 10 ticks;
breeding plays egg-plop with the dropped egg; each crack plays egg-crack and
hatching plays egg-hatch (both `BLOCKS`, volume 0.7) plus break particles
from `destroyBlock`; boosted placement and cracking emit level event 3009's
3–6 specks per face. Differences: Java sprays 30 terrain particles a tick at
the head; this sprays two crack particles a tick on the dug block, keeping
the bounded request queue small. Egg specks use the egg's own texture rather
than Java's `egg_crack` sprite and a positional count instead of the client
random. Scenting's 1.3 baby pitch is moot because snifflets never scent here.
Sniffer step and eat sounds use the shared defaults. LAN clients receive the
particles; entity sounds stay host-local like every other mob cue. Ambient
calls are suppressed during searching/digging, and digging reduces collision
height by Java's 0.4 blocks. Search/idle pose animation is simplified (no
keyframed head/leg animation).

Box16 selection outlines clip the pitcher crop's below-cell -1/16
extension; physical collision retains that extension through the shared
physics hook. Mature flower outline and plant-offset jitter are simplified.
Low-light crop destruction follows the existing engine's support checks
rather than a complete Java neighbor-light update port. No owner ordinary
planting/breeding/farming session or active-sniffer frame-time scene was run.
Survival acquisition of the first egg awaits Track D's archaeology table;
this worktree alone has no natural sniffer acquisition.
